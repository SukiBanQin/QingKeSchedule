# P3R blue-and-white concept archive

This folder freezes the first QingKe iPhone Web Demo direction inspired by
Persona 3 Reload. It is intentionally archived before the visual direction is
reconsidered.

- `page.tsx` contains the prototype screens and interactions.
- `globals.css` contains the full visual treatment.
- `app/page.tsx` and `app/globals.css` temporarily re-export this snapshot so
  the last working preview remains available until the next concept replaces it.

Do not extend this concept in place. Keep or remove it only after the new
direction has been reviewed.
