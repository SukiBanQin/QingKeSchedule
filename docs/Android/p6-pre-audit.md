## A01 核对

- Android 根路由只在联合状态为 `READY` 且 `semester == null` 时进入首次设置；加载失败不会误当成空数据。
- 首次设置和正式设置复用同一学期草稿与保存路径。真实 API 37 证据已覆盖清数据冷启动、创建学期、进入主壳、
  `force-stop` 后仍直接进入主壳。
- 首次设置页包含 Android 系统 `OpenDocument` 导入入口。A10 真实面板证据已覆盖从无学期状态导入有效 iOS 文件，
  确认后离开首次设置进入主壳；取消和解析失败不改变原路由。导入 `semester:null` 后重新进入首次设置并可关闭重开。
- iOS `AppRootView` 也是“未加载／无学期／主标签壳”三段路由；Android 的系统文件面板是已记录的平台对应实现。

因此 A01 不缺实现或测试，只缺把已经分散在 P3-02 与 A10 的用户确认明确收口为 A01 验收。
