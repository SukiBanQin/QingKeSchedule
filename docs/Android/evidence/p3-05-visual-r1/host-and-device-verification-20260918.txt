== 环境说明 ================================================================
本会话的文件沙箱只允许写入工作区，Gradle 用户目录、Android 用户目录与 TMPDIR 默认位置不可写，
因此本次构建使用可写临时目录（不改变仓库配置、不影响其他窗口）：
  JAVA_HOME=/Applications/Android Studio.app/Contents/jbr/Contents/Home
  GRADLE_USER_HOME=<tmp>/qingke-gradle（首次从用户缓存复制，未联网下载）
  ANDROID_USER_HOME=<tmp>/qingke-android-home（含 debug.keystore 与 adb key 副本）
  TMPDIR=<tmp>/qingke-tmp，JAVA_TOOL_OPTIONS=-Djava.io.tmpdir=<tmp>/qingke-tmp -Duser.home=<tmp>/qingke-userhome
  sdk.dir 继续使用 Android/local.properties 的既有配置
