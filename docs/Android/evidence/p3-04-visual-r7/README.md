# P3-04 视觉 R7：TODAY ADD 白框与细线十字

本轮只重拍 TODAY 右下角 ADD；没有沿用 R6 截图。所有图片均由最终 debug 生产 APK 在 API 37 ARM64 `emulator-5554` 取得，课程 `VisualR5` 已保存并在 TODAY 中可见。

- `today-add-light-100.png`：浅色、`font_scale=1.0`。黄色 64dp ADD 的四边半透明白色内框、右上白色折角和细线十字均可辨识；`ADD` 保持粗体 terminal 字形。
- `today-add-dark-100.png`：深色、`font_scale=1.0`。确认白框完整绕黄色底一圈，折角及其轻影不遮污染白框，细线十字仍居中。
- `today-add-dark-130.png`：深色、`font_scale=1.3`。确认较大字体下 ADD 标签仍完整、未裁切，白框、折角和平台无关的细线十字保持可见。

自动化像素回归在浅／深色及 100%／130% 下分别验证：四边白色内框存在、黑色内框为零、白色折角及轻影存在；25dp 自绘十字横竖中心、等臂、对称，并限制笔画宽度上限；`ADD` 文本仍存在。这些断言会拒绝 R6 的“无白框＋粗文本加号”实现。
