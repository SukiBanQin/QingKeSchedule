== 测试与实现的迭代记录（负向对照）=========================================
1) 面板 testTag 原先位于 14dp 内边距之后，captureToImage() 只覆盖内边距区域，
   「settings-semester-panel cyan rail pixels=0」失败；把 testTag 移到面板外层节点（含背景、
   边框与左侧竖线）后同一断言通过——说明测试检查的是真实绘制的青色竖线，而不是语义存在。
2) 底部卡片展开态在 1080x2400 下会被底部标签栏遮住黄色底线（「semester-save signal underline=0」）；
   改为先滚到页面底部占位（settings-bottom-spacer）再断言，100% 与 130% 均通过。
3) 早期尝试在文件顶层声明 index 字体（Typeface.create），会让纯 JVM 用例
   QingKeAppColorTest 触发 ExceptionInInitializerError；改为惰性 object（TerminalTypography）后 104 tests 全绿。
