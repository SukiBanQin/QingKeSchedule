三、失败原因

AndroidJUnit4 在实例化 RoomScheduleRepositoryTest 时拒绝了三个非 void 的 @Test 方法：

Invalid test class 'com.qingke.schedule.persistence.RoomScheduleRepositoryTest':
  1. Method cancellationPropagatesFromReadAndRollsBackWrite() should be void
  2. Method invalidWriteAndInjectedFailureRollBack() should be void
  3. Method emptyRoundTripOrderDuplicatesAndReopen() should be void

源码中这三个用例使用表达式函数返回 runBlocking 结果，而最后一句均为
File.delete()；因此 Kotlin 编译器生成了 boolean 方法。javap 独立核对为：

public final boolean emptyRoundTripOrderDuplicatesAndReopen();
public final boolean invalidWriteAndInjectedFailureRollBack();
public final void deleteFirstDuplicateAndKeepsClockContract();
public final boolean cancellationPropagatesFromReadAndRollsBackWrite();

所以本次已解除设备环境门槛，但发现了 Android 测试入口缺陷。Room schema、
重开数据库、事务回滚、取消传播、外键级联、重复 ID／顺序及损坏数据断言仍没有
实际运行，不得据此宣称 P2-01 已验证或已审查通过。
