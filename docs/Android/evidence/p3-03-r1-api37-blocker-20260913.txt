P3-03-R1 API 37 ARM64 AVD 路径更正与恢复证据
====================================================

日期：2026-09-13

本文件保留先前失败记录，但更正其环境结论。先前四次失败启动实际命中了错误的同名 AVD：
`/Users/takagisan/.android/avd/qingke-api37-r3-arm.ini`，其中 `target=android-0`。该副本在
18:26--18:27 被本轮错误启动尝试更新；它不是本任务指定的 API 37 环境。因此其中的 TCG、`adb shell`
不响应、HVF 未启用及 QEMU `SIGSEGV` 不能用来判定 API 37 ARM64 宿主环境阻断，也不能据此断言
Emulator 37.2.7 没有可用的 ARM64 加速路径。

本轮恢复时只使用正确的隔离副本：

```
ANDROID_HOME=/Users/takagisan/Library/Android/sdk-qingke-api37
ANDROID_SDK_ROOT="$ANDROID_HOME"
ANDROID_AVD_HOME=/Users/takagisan/.android/qingke-api37-r3-avd
"$ANDROID_HOME/emulator/emulator" -avd qingke-api37-r3-arm \
  -no-snapshot -no-window -gpu software -port 5584 -verbose
```

正确 AVD 的 ini 为
`/Users/takagisan/.android/qingke-api37-r3-avd/qingke-api37-r3-arm.ini`，其中
`target=android-37`。启动原始日志确认它加载 `android-37.0/google_apis/arm64-v8a`，QEMU 参数含
`-enable-hvf`，并报告 Hypervisor.Framework 加速工作。启动后 `adb devices -l` 只有
`emulator-5584`；`sys.boot_completed=1`、`ro.build.version.sdk=37`、
`ro.product.cpu.abi=arm64-v8a`。
