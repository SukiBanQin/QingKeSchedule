一、最小测试入口修正

修改文件：
Android/app/src/androidTest/java/com/qingke/schedule/persistence/RoomScheduleRepositoryTest.kt

三个 AndroidJUnit4 测试由表达式函数改为普通块体方法，块体内调用 runBlocking：
- emptyRoundTripOrderDuplicatesAndReopen
- invalidWriteAndInjectedFailureRollBack
- cancellationPropagatesFromReadAndRollsBackWrite

原因：三个表达式函数的 runBlocking 最后结果是 File.delete() 的 Boolean，Kotlin 因此生成
boolean 测试方法，AndroidJUnit4 拒绝执行。还将事务故障注入调用改为
repository(file, beforeCommit = { error("injected") })：R1 测试工厂新增 beforeRead 参数后，
旧尾随 lambda 的绑定目标发生变化；显式命名恢复原有提交前故障注入语义，未删除、跳过或放宽断言。
